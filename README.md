# 🛡️ AI-Based Industrial Risk Detection System

An intelligent surveillance system built to identify hazardous situations in industrial environments using real-time computer vision and automated alert mechanisms.

---

## 📌 Project Overview

This system continuously analyzes live video streams to detect potential risks such as fire outbreaks and worker collapse. Upon detection, it immediately activates alert systems to ensure rapid response and safety.

---

## 🎯 Objectives

- Enhance industrial safety through automation  
- Reduce human dependency for monitoring  
- Enable instant alert generation during emergencies  

---

## ⚡ Features

- 🔍 Real-time video analysis using AI  
- 🔥 Fire detection using trained YOLO model  
- 🧍 Human fall detection using pose estimation  
- 🚨 Instant alert triggering mechanism  
- 🔔 ESP32-based buzzer alert system  
- 📩 Integrated SMS and email notifications  

---

## 🔄 System Flow

1. Capture live video feed  
2. Process frames using AI models  
3. Identify abnormal events  
4. Trigger alerts via hardware and communication systems  

---

## 🧰 Tech Stack

- Python  
- OpenCV  
- YOLO (Ultralytics)  
- MediaPipe  
- Flask  
- ESP32 (IoT)  
- Twilio API
